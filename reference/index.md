# Package index

## All functions

- [`add_longwave()`](http://flare-forecast.org/ropenmeteo/reference/add_longwave.md)
  : Add longwave to ensemble forecast dataframe using Idso and Jackson
  (1969). Requires cloud cover and temperature variables in input data
  frame.
- [`convert_to_efi_standard()`](http://flare-forecast.org/ropenmeteo/reference/convert_to_efi_standard.md)
  : Convert units and names to CF and Ecological Forecasting Initiative
  standard
- [`daily_to_hourly()`](http://flare-forecast.org/ropenmeteo/reference/daily_to_hourly.md)
  : Convert daily climate projections to hourly time-step
- [`get_climate_projections()`](http://flare-forecast.org/ropenmeteo/reference/get_climate_projections.md)
  : Download point-level climate projections using open-meteo API
- [`get_ensemble_forecast()`](http://flare-forecast.org/ropenmeteo/reference/get_ensemble_forecast.md)
  : Download point-level ensemble weather forecast using open-meteo API
- [`get_forecast()`](http://flare-forecast.org/ropenmeteo/reference/get_forecast.md)
  : Download point-level weather forecast using open-meteo API
- [`get_historical_weather()`](http://flare-forecast.org/ropenmeteo/reference/get_historical_weather.md)
  : Download point-level historical weather (ERA5) using open-meteo API
- [`get_seasonal_forecast()`](http://flare-forecast.org/ropenmeteo/reference/get_seasonal_forecast.md)
  : Download point-level seasonal weather forecast using open-meteo API
- [`glm_variables()`](http://flare-forecast.org/ropenmeteo/reference/glm_variables.md)
  : Get set of variables required for the GLM model
- [`six_hourly_to_hourly()`](http://flare-forecast.org/ropenmeteo/reference/six_hourly_to_hourly.md)
  : Convert 6 hour seasonal forecast to hourly time-step
- [`write_glm_format()`](http://flare-forecast.org/ropenmeteo/reference/write_glm_format.md)
  : Write ensemble forecast dataframe to General Lake Model formatted
  csv files
